# 전통 저조도 개선 기법이 야간 객체 탐지에 미치는 영향: 실험 요약

## 1. 연구 질문

야간 도로 영상에 학습이 필요 없는 전통 저조도 개선(low-light enhancement) 기법을 전처리로 적용하면 객체 탐지 성능이 오르는가? 오른다면 실시간 처리가 가능한 기법은 무엇인가?

## 2. 실험 설정

| 항목 | 내용 |
|---|---|
| 개선 기법 | Gamma 보정, CLAHE, HE, AGCWD, MSRCR, LIME, Dong, BIMEF (원본 포함 9개 조건) |
| 데이터셋 | BDD100K 야간, ExDark, ACDC 야간, DarkDriving. 각 300장(seed 42), 총 1,200장 |
| 탐지기 | BDD100K로 학습된 YOLO26s·YOLO26m, 입력 640·960 (탐지 설정 4개, 기준 yolo26s 640). 재학습 없음 |
| 탐지 지표 | AP50, AP50-95, F1(conf 0.25, IoU 0.5), 객체 크기별 AP50 |
| 화질 지표 | NIQE, BRISQUE, MUSIQ, CLIP-IQA (무참조). DarkDriving은 정렬된 주간 영상으로 PSNR, SSIM, LPIPS도 계산 |
| 환경 | RTX 3070, 전통 기법은 모두 CPU(NumPy·OpenCV·SciPy) 구현 |

아래 표의 ΔAP50은 원본 대비 AP50 변화량을 %p로 나타낸 값입니다. 4개 데이터셋 평균이고, 기준이 되는 원본 평균 AP50은 47.9%입니다.

## 3. 주요 결과

### 3.1 기법별 비교 (yolo26s 640)

| 기법 | 원리 | ΔAP50 (%p) | 개선 시간 (ms/장) | 30fps 가능 |
|---|---|---:|---:|---|
| CLAHE (clip 2.0) | 타일별 대비 제한 히스토그램 평활화 | **+0.45** | 10~14 | O |
| Gamma (γ 1.5) | 고정 감마 곡선 | **+0.06** | 1 | O |
| BIMEF | 노출 합성 기반 다중 노출 융합 | −0.23 | 1,118 | X |
| AGCWD (α 0.5) | 가중 분포 기반 적응형 감마 | −0.50 | 5~7 | O |
| Dong | 반전 영상에 dehazing 적용 | −4.87 | 190 | X |
| MSRCR | 다중 스케일 Retinex + 색 복원 | −6.95 | 213 | X |
| LIME | 조명 맵 추정 후 나눗셈 (BM3D 제외) | −7.49 | 2,392 | X |
| HE | 전역 히스토그램 평활화 | −8.78 | 11 | O |

- **원본보다 평균 AP50이 오른 기법은 CLAHE와 Gamma 두 개뿐이고, 상승 폭도 0.5%p 미만입니다.**
- **이미지 단위 짝 부트스트랩(2,000회)으로 F1 차이의 95% 구간을 구했습니다.**
  - 유의하게 오른 경우는 Gamma의 BDD100K와 DarkDriving 두 칸뿐입니다.
  - HE와 Dong은 4개 데이터셋 모두에서 유의하게 떨어졌습니다.
- **탐지기 설정 4개(YOLO26s·m × 640·960) 모두에서 순위가 거의 같았습니다.** 상위 4개(CLAHE, Gamma, BIMEF, AGCWD)는 0 근처이고, 하위 4개는 모든 설정에서 −3.5%p 이하입니다.

### 3.2 파라미터 비교

| 기법 | 약 | 중 | 강 | 최강 |
|---|---:|---:|---:|---:|
| Gamma (γ 1.2 / 1.5 / 2.0 / 2.5) | **+0.72** | +0.06 | −0.48 | −1.37 |
| CLAHE (clip 1.0 / 2.0 / 4.0) | **+0.75** | +0.45 | −1.09 | |
| AGCWD (α 0.25 / 0.5 / 0.75) | −0.15 | −0.50 | −3.08 | |

- **세 기법 모두 보정 강도와 ΔAP50 사이에 단조 감소 관계가 나타났습니다.** 4개 탐지 설정 모두에서 같은 순서였습니다.
- **알맞은 강도는 데이터셋에 따라 달랐습니다.**
  - 가장 어두운 DarkDriving에서는 강한 Gamma가 유리했습니다(γ 2.0에서 +3.9%p).
  - ExDark에서는 강할수록 크게 떨어졌습니다(γ 2.5에서 −9.2%p).

## 4. 해석

1. **잡음 증폭:** HE, LIME, MSRCR은 암부의 센서 잡음과 JPEG 블록 아티팩트를 함께 증폭합니다.
   - 대형 객체 AP50이 원본 69.1%에서 HE 57.4%, LIME 61.6%로 떨어졌습니다.
   - 소형 객체는 CLAHE(23.0 → 27.3%)처럼 오히려 오른 경우도 있었습니다.
   - 밝기 향상의 이득보다 경계 정보 손실이 컸던 것으로 보입니다.
2. **분포 이동(domain shift):** 탐지기가 야간 영상이 포함된 BDD100K로 학습되어, 입력 변화가 클수록 학습 분포에서 멀어집니다.
   - 실제로 강한 기법의 하락이 BDD100K에서 가장 컸습니다(LIME −16.1%p, HE −14.8%p).
3. **화질 지표와 탐지 성능의 불일치:** NIQE가 가장 좋은 기법(MSRCR, Dong, LIME, HE)이 탐지 성능은 가장 나빴습니다.
   - NIQE와 ΔAP50의 스피어만 상관은 4개 데이터셋 모두 양(0.18~0.63)이었습니다. NIQE가 좋을수록(낮을수록) 탐지가 떨어진다는 뜻입니다.
   - 사람 기준의 화질 지표로 탐지용 전처리를 고르면 안 된다는 근거입니다.

## 5. 결론

- **전통 저조도 개선은 야간 객체 탐지 성능을 의미 있게 올리지 못했습니다.** 효과가 있는 경우에도 1%p 미만입니다.
- **쓴다면 약한 보정만 쓰는 것이 좋습니다.**

| 기준 | 추천 | 근거 |
|---|---|---|
| 속도와 평균 성능 | CLAHE (clip 1.0) | ΔAP50 +0.75%p (최고), 10ms 내외. ACDC, DarkDriving에서 F1이 유의하게 상승 |
| 안정성 | Gamma (γ 1.2) | ΔAP50 +0.72%p, 1ms. 데이터셋별 순위 평균 1위, 최대 하락 −0.5%p |

## 6. 한계

- **선택 편향:** 추천 파라미터를 평가에 쓴 같은 300장으로 골랐습니다. 다른 seed의 표본으로 검증해야 합니다.
- **탐지기:** BDD100K로 학습한 탐지기 한 계열만 썼습니다. 주간 위주로 학습한 탐지기(예: COCO)에서는 결과가 달라질 수 있습니다.
- **구현:** LIME은 BM3D 잡음 제거를 뺀 구현입니다. 처리 시간은 Python·CPU 기준이라 C++나 GPU로 구현하면 달라집니다.
